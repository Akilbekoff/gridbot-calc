# Gridbot Calc 📊

Калькулятор доходности спотовой сетки (Grid Bot) — PWA приложение для Android.

## Установка на Android

1. Загрузи репозиторий на хостинг с HTTPS (например **GitHub Pages**)
2. Открой сайт в браузере Chrome на Android
3. Нажми меню (⋮) → **«Добавить на главный экран»**
4. Приложение появится на рабочем столе с иконкой

## Включить GitHub Pages

1. Settings → Pages
2. Source: **Deploy from branch**
3. Branch: `main` / `root`
4. Сохранить → сайт будет на `https://ВАШ_НИК.github.io/ИМЯ_РЕПО`

## Функции

- Ценовой диапазон (нижняя / верхняя / текущая цена)
- Количество сеток (слайдер 2–200)
- Инвестиции в USDT
- Комиссия мейкер / тейкер
- **Завершённые циклы в день** + прибыль
- **Завершённые циклы в месяц** + прибыль
- ROI / месяц, окупаемость
- Визуализация сетки
- Работает офлайн (Service Worker)
